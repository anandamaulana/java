2.6 — Proses Prediksi Omzet

PrediksiForm → RegresiLinearService

Paling detail — persis kerangka kerja algoritma Bab III: prapemrosesan, pembentukan variabel, kalkulasi komponen dasar, pencarian a & b, hingga evaluasi MAPE.

flowchart TD
  start(("Mulai")) --> a["Staf pilih Bulan & Tahun Target\npada PrediksiForm"]
  a --> b["Ambil data omzet_bulanan\nbulan sama, tahun kurang dari target\n(TransaksiDAO.getOmzetByBulan)"]
  b --> c{"Jumlah data historis\nn ≥ 2?"}
  c -- "Tidak" --> d["Tampilkan peringatan:\n'Data historis belum cukup'"]
  d --> endA(("Selesai"))
  c -- "Ya" --> e["Bentuk variabel:\nX = urutan tahun ke-n, Y = total omzet"]
  e --> f["Hitung ΣX, ΣY, ΣXY, ΣX²"]
  f --> g["Hitung b = (n·ΣXY − ΣX·ΣY) / (n·ΣX² − (ΣX)²)"]
  g --> h["Hitung a = (ΣY − b·ΣX) / n"]
  h --> i["Substitusi X target = n+1\nke persamaan Y = a + bX"]
  i --> j["Hitung MAPE dari nilai fitting\nvs data aktual (MapeEvaluator)"]
  j --> k["Render angka hasil + grafik tren\n(ChartHelper.buatPanelTren)"]
  k --> l{"Staf klik\n'Simpan Hasil Prediksi'?"}
  l -- "Ya" --> m["Tulis baris baru ke\ntabel hasil_prediksi (PrediksiDAO)"]
  m --> endB(("Selesai"))
  l -- "Tidak" --> endB

Enam langkah komputasi (ringkas Bab III)

  1. Prapemrosesan — agregasi transaksi_harian menjadi omzet_bulanan per tahun-bulan.
  2. Pembentukan variabel — X = urutan waktu historis, Y = omzet aktual bulan tersebut.
  3. Kalkulasi komponen dasar — ΣX, ΣY, ΣXY, ΣX² dari seluruh data Year-over-Year.
  4. Pencarian a & b — metode kuadrat terkecil (Least Square Method).
  5. Pembentukan model & prediksi — substitusi X target baru ke Y = a + bX.
  6. Evaluasi & visualisasi — hitung MAPE, render grafik tren pada antarmuka.

3.2 — Import Data Transaksi

ImportDataForm → ExcelImportService → TransaksiDAO 
sequenceDiagram
  actor S as Staf Operasional
  participant UI as ImportDataForm
  participant Svc as ExcelImportService
  participant POI as Apache POI (Workbook)
  participant DAO as TransaksiDAO
  participant DB as MySQL

  S->>UI: Pilih file .xlsx, klik "Import ke Database"
  UI->>Svc: importFile(file, idUser)
  Svc->>DB: INSERT INTO import_log(...)
  Svc->>POI: WorkbookFactory.create(file)
  POI-->>Svc: Sheet baris transaksi
  loop tiap baris data
    Svc->>Svc: parseTanggal() / parseNominal()
    alt baris valid
      Svc->>DAO: insertTransaksi(TransaksiHarian)
      DAO->>DB: INSERT INTO transaksi_harian
      Svc->>Svc: jumlahBaris++
    else baris gagal parse
      Svc->>Svc: catat pesanGagal, jumlahGagal++
    end
  end
  Svc->>DB: UPDATE import_log SET status, jumlah_baris
  Svc-->>UI: HasilImport(jumlahBaris, jumlahGagal, pesanGagal)
  UI-->>S: Tampilkan ringkasan + daftar baris gagal di log

3.3 — Proses Prediksi Omzet

PrediksiForm → RegresiLinearService → MapeEvaluator → ChartHelper → PrediksiDAO 
sequenceDiagram
  actor S as Staf Operasional
  participant UI as PrediksiForm
  participant Svc as RegresiLinearService
  participant DAO as TransaksiDAO
  participant DB as MySQL (omzet_bulanan)
  participant Mape as MapeEvaluator
  participant Chart as ChartHelper
  participant PDAO as PrediksiDAO

  S->>UI: Pilih bulan & tahun target, klik "Proses Prediksi"
  UI->>Svc: prediksi(bulan, tahun)
  Svc->>DAO: getOmzetByBulan(bulan, tahun)
  DAO->>DB: SELECT ... WHERE bulan=? AND tahun<? ORDER BY tahun
  DB-->>DAO: baris omzet_bulanan
  DAO-->>Svc: List OmzetBulanan

  alt n < 2
    Svc-->>UI: IllegalStateException("data tidak cukup")
    UI-->>S: Dialog peringatan, tombol Simpan nonaktif
  else n >= 2
    Svc->>Svc: hitung ΣX, ΣY, ΣXY, ΣX²
    Svc->>Svc: hitung koefisien b, konstanta a
    Svc->>Svc: hitung nilaiPrediksi = a + b·(n+1)
    Svc->>Mape: hitung(aktual[], fitting[])
    Mape-->>Svc: mapePersen
    Svc-->>UI: PrediksiResult
    UI->>Chart: buatPanelTren(hasil)
    Chart-->>UI: ChartPanel (JFreeChart)
    UI-->>S: Tampilkan a, b, prediksi, MAPE + grafik tren
    opt Staf klik "Simpan Hasil Prediksi"
      S->>UI: klik Simpan
      UI->>PDAO: simpan(hasil, idUser)
      PDAO->>DB: INSERT INTO hasil_prediksi
      DB-->>PDAO: id_prediksi
      PDAO-->>UI: OK
      UI-->>S: Dialog "Berhasil disimpan"
    end
  end
